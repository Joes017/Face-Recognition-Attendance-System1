Face Recognition Attendance System

Overview

The Face Recognition Attendance System is a computer vision-based application designed to automate the process of recording attendance. The system detects and recognizes registered faces and records attendance digitally, reducing the need for manual attendance tracking.

Features

* Detects faces using a camera.
* Recognizes registered individuals from stored face data.
* Automatically records attendance.
* Reduces manual effort and improves the efficiency of attendance management.

Technologies Used

* Python
* OpenCV
* Face Recognition Library
* NumPy
* CSV / Database for attendance records

Working

1. Registered face images are stored in the system.
2. The camera captures video frames in real time.
3. The system detects faces in each frame.
4. Detected faces are compared with the registered face data.
5. Once a face is recognized, the attendance is recorded.
